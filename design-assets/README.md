# LiftMark Brand — Final Assets (v3.0)

Primary brand: **lift.md**. Family: **LiftMark** (formal / App Store), **LiftMark Format** (open format, was "LMWF"), **lift.md format**.

Open **`LiftMark-Brand-Book.html`** (or the PDF) for the full guidelines.

## The mark
A **#** (markdown / plain text) racked on a **barbell** (lifting), framed by the plates, on a subtle blue-gradient tile. No letters — it carries every name. Blue tile is primary; ink and light are alternates. The **favicon is the same mark, just scaled** (keep it on the blue tile).

## Gradients — one rule
Keep surface gradients inside one hue; never fade blue into orange (it browns).
- `--lm-gradient-tile`   `#356CFF -> #1F46CE` — tiles / surfaces
- `--lm-gradient-orange` `#ED5305 -> #FF8A3D` — in-app accents, progress
- `--lm-gradient-energy` `blue -> magenta -> orange` — thin DECORATIVE rules only (cover/footer/OG); never a fill

## Core colors
LiftMark Blue `#2D5BFF` · Blue 600 (links) `#1E45E6` · LiftMark Orange `#FF6A1A` · Ink `#0E1116`
